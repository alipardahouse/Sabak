# Study Library

1. Put your PDFs in `www/pdf/` using these names:
   - book01.pdf ... book10.pdf
   - assignment01.pdf ... assignment10.pdf
2. Push to GitHub (branch `main`).
3. Download `StudyLibrary.apk` from the repo's **Releases** page.

Titles/file names can be changed at the top of the script in `www/index.html`.
